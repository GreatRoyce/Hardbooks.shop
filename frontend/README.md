# Frontend App

This folder contains the Hardbooks React application.

## Scripts

- `npm run dev` - start local dev server
- `npm run build` - production build
- `npm run lint` - lint source files
- `npm run preview` - preview production build

## Deployment

Deployment is configured from the repository root via `../vercel.json`.
Do not add a second Vercel config here.

## Key Conventions

- Keep import paths relative and readable.
- Match file-name casing exactly.
- Prefer feature modules under `src/modules`.
